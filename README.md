Foi adicionada uma funcionalidade que permite pesquisar utilizadores pelo nome ou por parte do nome.

Para utilizar esta funcionalidade, basta executar o ficheiro api_utilizadores.py e introduzir o nome pretendido quando solicitado.

O programa apresenta o nome e o email dos utilizadores encontrados, em que caso não existam correspondências, apresenta uma mensagem a informar que não foram encontrados utilizadores.
